## 🚀 Setup Phases

### **PHASE 1: Create Your Main Folder**
1. Create a new folder on your computer called `ej-tours-website`
2. This will be your main project folder

### **PHASE 2: Add the Core Files**
Copy and paste these three files into your main folder:
- `index.html`
- `styles.css`
- `script.js`

## 📝 Notes

### Image Tips:
- Use high-quality images (not blurry or pixelated)
- Try to keep file sizes under 500KB each for faster loading
- Use JPG format for photos
- Make sure images are landscape orientation for tour cards
- Optimize images using tools like TinyPNG before adding them

### Where to Find Images:
- Your own photography
- Stock photo websites (Unsplash, Pexels, etc.)
- Professional photographer
- Cape Town tourism websites (with permission)

### Current Placeholder Images:
The original HTML used Unsplash URLs. Once you add your own images to the `images` folder with the correct names, the website will automatically use them instead.

## 🔧 Troubleshooting

**Images not showing?**
- Check that image names match EXACTLY (including .jpg extension)
- Check that images are in the `images` folder
- Check that the `images` folder is in the same location as `index.html`
- Try refreshing your browser (Ctrl+F5 or Cmd+Shift+R)

**Website not working?**
- Make sure all three files (index.html, styles.css, script.js) are in the same folder
- Check your browser console (F12) for errors
- Ensure you're opening `index.html` and not the CSS or JS files
